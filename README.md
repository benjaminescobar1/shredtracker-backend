# ShredTracker Backend

Benjamin Escobar | SWDV 691 Capstone

ShredTracker helps users track workouts, strength progress,
and weight-loss goals.

This repository contains the backend API and MySQL database
setup. The API receives requests from the frontend, validates
data, saves records, and calculates progress.

## Planned Technologies
- Node.js and Express
- MySQL
- Heroku for application hosting

## Planned MVP Features
- User registration, login, and logout
- Workout and exercise records
- Workout volume and strength comparisons
- Body-weight records and weight-loss goals
- Dashboard summaries and goal progress calculations

## Stretch Feature
Saved workout routines that users can reuse when logging workouts.

## Design Documents
The design folder contains the database and service layer designs.

## Project Status
Design and setup. Application development has not started.
